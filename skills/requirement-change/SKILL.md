# 需求变更（Autopilot 任务9）

**作用**：当已有项目需要变更时，AI 自动分析变更影响范围，只增量重做受影响的阶段。

## 前置条件

- 目标项目已有产出文档（需求分析、PRD、设计等）
- 知识库必须已存在

## 执行步骤

1. **读取 Autopilot 框架目录的 `README.md`**：获取完整流程规则
2. **用户描述变更内容**：指定需求标识 + 变更内容
3. **推荐 CodeGraph 辅助**：如果项目安装了 CodeGraph，先用 `codegraph fn-impact <函数名>` 快速评估变更影响半径，比 AI 手动分析更精确
4. **AI 自动分析影响范围 + 分级**：
   ```
   📊 变更影响分析
   需求标识：user-login
   变更内容：增加忘记密码功能
   影响模块：登录模块、用户服务
   预计影响文件：约6个
   变更级别：M
   受影响阶段：02-prd.md（增加用户故事）、03-software-design.md（新增密码重置流程）
   可保留阶段：01-requirements-analysis.md（整体需求不变）
   ```
4. **确认变更范围和级别**：用户确认或调整
5. **按级别执行增量重做**：只重做受影响的阶段
6. **继续后续流程** → 测试报告 → 知识库增量更新

## 用户输入示例

```
需求变更：user-login 登录页面增加忘记密码链接，点击后跳转到忘记密码页面
```

```
需求变更：message-push 新增邮件通知支持，级别：M
```
