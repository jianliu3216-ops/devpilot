# 代码实现（Autopilot 任务6）

**作用**：按照设计文档实现功能代码，遵循 TDD 原则。代码直接写入目标项目。

## 前置条件

- 任务5（软件设计/变更策略）必须已完成，用户已确认
- 知识库（如存在）用于参考编码风格和目录结构

## 执行步骤

1. **读取 README.md**：获取流程规则
2. **读取所有依赖文档**：知识库 + 需求分析 + PRD + 软件设计/变更策略
3. **按变更级别执行**：

| 级别 | 实现方式 |
|------|---------|
| S 级 | 直接改代码 + 自动化测试 |
| M 级 | TDD：先写测试 → 再写实现 → 重构 |
| L 级 | 按策略文档分批次执行，每批次验证 |

4. **测试代码目录确认**（M/L级）：
   ```
   📂 测试代码目录确认
   默认路径：[目标项目]/tests/{需求标识}/
   是否需要调整路径？
   ```
5. **输出**：源代码 + 测试代码（均写入目标项目目录）
6. **运行测试**确保全部通过
7. **等待用户确认**后才能进入测试用例阶段

## 用户输入示例

```
确认设计，开始代码实现
```

```
确认变更策略，开始按批次实现
```
