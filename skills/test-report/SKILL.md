# 测试报告（Autopilot 任务8）

**作用**：执行测试，生成完整的测试报告。完成后自动触发知识库增量更新（任务8.5）。

## 前置条件

- 任务7（测试用例/回归验证）必须已完成，用户已确认
- 代码已实现且通过初步测试

## 执行步骤

1. **读取 Autopilot 框架目录的 `README.md`**：获取完整流程规则
2. **读取测试用例文档**：`04-test-cases.md` 或 `04-regression-checklist.md`
3. **运行完整测试套件**，收集测试结果
4. **按变更级别输出**：

| 级别 | 输出 |
|------|------|
| S 级 | 简要结果报告 |
| M 级 | 完整测试报告 |
| L 级 | 完整测试报告 |

5. **输出文件**：`[目标项目]/docs/{需求标识}/05-test-report.md`
   - 测试概览（总共多少用例）
   - 测试结果统计（通过/失败数量）
   - 失败用例分析（原因 + 建议）
   - 覆盖率统计（如工具支持）
6. **自动触发知识库增量更新**（任务8.5）

## 用户输入示例

```
确认测试用例，运行测试生成报告
```

```
确认回归验证清单，运行测试生成报告
```
