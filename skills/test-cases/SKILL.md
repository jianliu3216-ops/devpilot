# 测试用例 / 回归验证（Autopilot 任务7）

**作用**：整理输出完整的测试用例文档或回归验证清单。

## 前置条件

- 任务6（代码实现）必须已完成，用户已确认
- S 级变更跳过此步骤（自动化测试已覆盖）

## 执行步骤

1. **读取 README.md**：获取流程规则
2. **读取所有依赖文档**：PRD + 已实现代码
3. **按变更级别输出**：

| 级别 | 输出文档 | 内容 |
|------|---------|------|
| S 级 | 跳过 | 自动化测试已覆盖 |
| M 级 | `04-test-cases.md` | 功能测试用例、边界测试用例、异常测试用例 |
| L 级 | `04-regression-checklist.md` | 编译验证、核心功能验证、兼容性验证（勾选清单） |

4. **输出文件**：`[目标项目]/docs/{需求标识}/04-test-cases.md` 或 `04-regression-checklist.md`
5. **等待用户确认**后才能进入测试报告阶段

## 用户输入示例

```
确认代码实现，生成测试用例
```

```
确认代码实现，生成回归验证清单
```
