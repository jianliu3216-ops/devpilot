# 生成 PRD（Autopilot 任务4）

**作用**：基于已确认的需求分析，生成完整的 PRD 产品需求文档。

## 前置条件

- 任务3（需求分析）必须已完成，用户确认了需求分析
- S 级变更跳过此步骤

## 执行步骤

1. **读取 Autopilot 框架目录的 `README.md`**：获取完整流程规则
2. **读取需求分析文档**：`[目标项目]/docs/{需求标识}/01-requirements-analysis.md`
3. **读取知识库**（如存在）：`PROJECT_KNOWLEDGE_BASE.md`
4. **输出文件**：`[目标项目]/docs/{需求标识}/02-prd.md`
   - 用户故事（谁，需要什么，为什么）
   - 功能规格说明书（每个功能详细描述）
   - 交互流程（用户操作流程）
   - 验收标准（满足什么条件才算做完）
   - 知识库锚点（关联版本、模块域、流程图、预计变更）
5. **等待用户确认**后才能进入下一阶段

## 用户输入示例

```
生成PRD
```

```
确认需求分析，继续生成 PRD
```
