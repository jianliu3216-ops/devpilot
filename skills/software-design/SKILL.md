# 软件设计 / 变更策略（Autopilot 任务5）

**作用**：基于 PRD 进行技术设计。根据变更级别自动选择输出类型。

## 前置条件

- 任务4（PRD）必须已完成，用户已确认
- S 级变更跳过此步骤

## 执行步骤

1. **读取 Autopilot 框架目录的 `README.md`**：获取完整流程规则
2. **读取 PRD 文档**：`[目标项目]/docs/{需求标识}/02-prd.md`
3. **读取知识库**（如存在）
4. **按变更级别输出**：

| 级别 | 输出文档 | 内容 |
|------|---------|------|
| M 级 | `03-software-design.md` | 架构图、模块划分、接口定义、数据结构、依赖关系 |
| L 级 | `03-change-strategy.md` | 变更范围、分批次计划、风险点、回滚方案 |

5. **输出文件**：`[目标项目]/docs/{需求标识}/03-software-design.md` 或 `03-change-strategy.md`
6. **等待用户确认**后才能进入代码实现

## 用户输入示例

```
确认 PRD，继续软件设计
```

```
确认 PRD，继续生成变更策略文档
```
