# 00-原始需求：知识库日常增量（kb-incremental-ops）

- 日期：2026-09-30
- 来源：`docs/DEVPILOT_VERSION_PLAN.md` §8（2.7.0）
- 级别：M（规划既定；用户已授权「不用问我了，全干了先」，免逐级确认）

## 原始描述

用户痛点：「知识库弄一次半天，导致大家不敢更」。2.6.0 已补齐骨架+机器索引形态，但日常路径仍缺硬约束：单点 bug 修复也可能被拉去全量重扫。本版本把「日常只增量、全量仅三种情形」固化为规则与脚本检查。

## 要点（来自规划 §8）

1. KNOWLEDGE_BASE_RULES 新增「日常增量禁令」：禁止单点 bug 全量重扫；任务2（全量）仅三种情形：首次生成 / 架构剧变 / 用户显式要求且确认耗时
2. `jit-project-knowledge-base-update` SKILL 收紧为白名单更新：INDEX 对应条目、DETAIL 命中节、需求 CHANGELOG 锚点、ADMITTED 刷新；禁止重写无关模块
3. `jit-project-devpilot-status` 扫描加检查：需求目录有 05 但知识库缺该需求 INDEX 条目 → 状态「未完成」
4. CLAUDE.md 知识库更新规则节补禁令一行

## 验收要求

- 全量重扫入口收窄到三种情形且有确认话术
- update SKILL 有白名单与禁改清单
- scan-status 能输出「未完成（缺 INDEX 条目）」
- 文档链 00–05 齐全
