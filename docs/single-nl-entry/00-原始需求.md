# 00 原始需求：单一入口与自然语言触发（single-nl-entry）

- 需求标识：`single-nl-entry`
- 中文名：单一入口与自然语言触发
- 所属版本规划：`docs/DEVPILOT_VERSION_PLAN.md` **2.3.0**
- 创建时间：2026-09-30
- 原始诉求（用户原话归纳）：

> 工具能力要精简。未来就一个入口，剩下全是自然语言识别和触发。
> Skill 太多、雷同太多；小问题不该走完整流水线。

## 需求描述

用户激活 DevPilot 后，只需要记住一个入口（`/jit-devpilot-init` 或「激活DevPilot」）；其余所有能力通过既有自然语言关键字表触发，不再要求用户记忆多个 `/jit-*` 斜杠命令。

## 范围

1. 激活菜单收口：斜杠命令推荐 ≤ 1 条，其余改为「你可以说：…」自然语言表。
2. `CLAUDE.md`「触发方式二」降级为兼容入口，非推荐。
3. `DEVPILOT.md`、README 等入口叙述同步收口。
4. 各 Skill YAML `description` 注明「由流水线内部调用，用户请用自然语言 xxx」。
5. 路由硬规则：已激活会话匹配 NL 关键字 → 直接进任务；模糊句 → 先确认；修补类描述 → 建议级别 S。

## 非目标（本版本禁止）

- 不写 `state.yaml` / guard（2.5.0）
- 不改 `verify-kb-facts.js` 算法（2.4.0 范畴）
- 不做知识库骨架/索引（2.6.0）
- 不翻译 Placet（3.0.0）
- 不删除 `skills/jit-*` 目录（实现保留）
- 不新增任何对外斜杠命令

- [ ] 自然语言表覆盖任务 2、3、4、5、6、7、8、8.5、9、事实门控、环境
