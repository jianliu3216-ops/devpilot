# 02 产品需求文档（PRD）：单一入口与自然语言触发（single-nl-entry）

- 日期：2026-09-30
- 级别：M（用户已确认）
- 上游：`00-原始需求.md`、`01-requirements-analysis.md`
- 上下文：本阶段仅依据 `.handoff/prd.context.md` 恢复，未复读 00/01 全文

## 1. 目标

激活 DevPilot 后，用户只需记住 **1 个入口**；其余能力全部由既有自然语言关键字触发。斜杠命令从用户菜单中消失（实现保留）。

## 2. 用户故事

| # | 作为 | 我希望 | 以至于 | 验收 |
|---|------|--------|--------|------|
| US1 | 新用户 | 激活后菜单告诉我「你可以说：需求：…」，而不是一排 `/jit-*` | 不用背命令就能走完流程 | 菜单斜杠推荐 ≤1 |
| US2 | 老用户 | 打旧斜杠命令仍能执行 | 迁移期不中断工作 | Skill 功能不删、行为不变 |
| US3 | 想快速修 bug 的用户 | 说「需求：改个超时」就被建议 S 级直改 | 不被拉进 PRD/设计马拉松 | 分析阶段给出 S 建议 |
| US4 | AI（会话协议） | 匹配 NL 关键字后直接进任务 | 不再向用户推销斜杠命令 | CLAUDE.md 协议明文禁止 |

## 3. 功能规格

### FR1 激活菜单收口（核心）

`skills/jit-devpilot-init/SKILL.md` 第 2 步操作菜单改为：

1. 顶部：版本号 + 目标项目（保留）
2. **斜杠命令区只列 1 条**：`/jit-devpilot-init`（激活）
3. 能力区全部改写为「你可以说：…」自然语言表（沿用 CLAUDE.md 触发方式一现有关键字，逐条对应任务 2、3、4、5、6、7、8、8.5、9、事实门控、环境、状态查看）
4. 明示：小修复直接说「需求：…」，等分级建议，不默认走完整流水线
5. 内部 Skill 说明改为：「以下由流水线自动调用，无需记忆斜杠名；旧斜杠仍可用（兼容）」

### FR2 触发表降级与路由硬规则（CLAUDE.md）

「触发方式二：Skill 命令」章节改为「兼容入口（非推荐）」，并新增三条硬规则（写入会话持久化协议）：

- R1：会话已激活 + 用户句子匹配 NL 表 → 直接进对应任务，禁止引导用户打 `/jit-*`
- R2：模糊句（如「帮我看看这个报错」）→ 必须确认是否走流水线 + 建议标识，不得直接开工具
- R3：修补类描述（单点、无新模块）→ 需求分析必须给出 S 级建议并等确认

### FR3 外围文档口径收口

`README.md`、`快速入门.md`、`DEVPILOT.md`、`docs/DEVPILOT_CLAUDE_CODE_GUIDE.md`：斜杠清单改为「一入口 + NL 表」口径；README L86「查看进度」改推 NL（如「查看状态」）。

### FR4 Skill YAML description 标注

10 个 `skills/jit-*/SKILL.md` 的 description 追加一句：「由 DevPilot 流水线内部调用；用户请使用自然语言：xxx」。

## 4. 交互流程（激活后）

```text
用户：激活DevPilot
AI：菜单（1 斜杠 + NL 表 + S 提示）
用户：需求：把超时从 3 秒改成 5 秒
AI：建议标识 + 确认 → 00 文件 → 分析 → 🔴建议 S 级（R3）
用户：确认 S → 直改代码 → 简要报告 → 增量知识库
```

## 5. 非功能需求

- NF1：不删除任何 Skill 目录与脚本；流水线内部调用路径不变
- NF2：NL 关键字表内容保持与 CLAUDE.md 一致，单一事实源为 CLAUDE.md，菜单只引用不另造
- NF3：全部改动为文档/文案，不引入新脚本、新依赖
- NF4：向后兼容：旧斜杠命令全部可用

## 6. 验收标准

- [ ] AC1 激活输出斜杠推荐 ≤ 1
- [ ] AC2 NL 表覆盖任务 2/3/4/5/6/7/8/8.5/9 + 事实门控 + 环境 + 状态
- [ ] AC3 10 个 Skill 目录仍在，SKILL.md 路径可被流水线找到
- [ ] AC4 「需求：<修补描述>」流程给出 S 建议
- [ ] AC5 零个新对外斜杠命令
- [ ] AC6 R1–R3 已写入 CLAUDE.md 会话协议
- [ ] AC7 R4 三层兜底 + 兜底菜单模板已写入 CLAUDE.md（规则）与 init SKILL（模板）；含 `菜单` 救援关键字
- [ ] AC8 自定义描述循环：菜单下给自定义一句话，能定位则执行；不能则给出 ≤2 个候选再问；两轮仍未定位必须点名；全程未开工具

## 7. 边界与风险

| 风险 | 处理 |
|------|------|
| 菜单与 CLAUDE.md 关键字漂移（两处维护） | NF2 单一事实源约束；菜单改动时必须对照触发表 |
| 依赖 init SKILL 的老文档（ guides、collective）引用旧菜单 | 本版本只收口 4 份外围文档 + init，其余引用不做全量清扫（避免范围膨胀），遗留引用属兼容层 |
| 用户仍习惯旧斜杠 | FR4 保留可用性，2.8.0 再加提示语 |

## 8. 范围外

规划 2.4–3.0 全部能力（瘦上下文强制、state/guard、骨架索引、增量运维、兼容提示、Placet 翻译）。
